Rookie Shorts Uploader 개인정보처리방침

시행일: 2026년 10월 17일

1. 프로그램 개요

Rookie Shorts Uploader(이하 "프로그램")는 개발자 본인의 YouTube 채널에 쇼츠 영상을 업로드하고 공개 시간을 관리하는 개인용 데스크톱 프로그램입니다. 프로그램은 개발자 본인의 컴퓨터에서만 실행됩니다.

2. 사용하는 Google 사용자 데이터

프로그램은 Google OAuth를 통해 사용자가 허용한 경우에만 YouTube Data API를 사용합니다.

  • https://www.googleapis.com/auth/youtube.upload: 영상 파일 업로드
  • https://www.googleapis.com/auth/youtube: 업로드한 영상의 상태 조회, 공개 상태 변경, 본인 채널 정보와 업로드 목록 조회

프로그램이 다루는 데이터는 채널 ID, 업로드한 영상의 ID·제목·설명·공개 상태·처리 상태입니다.

3. 데이터 저장

  • OAuth 인증 토큰은 사용자 컴퓨터의 로컬 폴더에만 저장됩니다.
  • 업로드 기록(영상 ID, 제목, 업로드·공개 시각)은 사용자 컴퓨터의 로컬 파일에만 저장됩니다.
  • 개발자 소유의 서버나 외부 데이터베이스로 데이터를 보내지 않습니다.

4. 데이터 공유

프로그램은 Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고·분석 목적으로 사용하지 않습니다. 데이터는 YouTube Data API를 통해 Google(YouTube)과 주고받는 것 외에는 전송되지 않습니다.

Rookie Shorts Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API 서비스

프로그램은 YouTube API Services를 사용합니다. 프로그램을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

6. 데이터 삭제와 권한 취소

  • 로컬에 저장된 토큰 파일과 업로드 기록 파일을 지우면 프로그램이 보관한 데이터가 모두 삭제됩니다.
  • 프로그램의 접근 권한은 Google 계정 보안 설정에서 언제든지 취소할 수 있습니다.
